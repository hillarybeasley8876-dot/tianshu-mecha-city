### G. Two rules to add to every brief

- **Shared files:** before `git commit -- <file>` on a file another unit may touch (`settle_cache.json`, `CONTRACTS.md`, `project.godot`, `FEEL.md`, `main.gd`, `enemy_base.gd`), run `git diff -- <file>`. If it holds someone else's hunk, wait or ask.
